# Web i18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Internationalize the flashkarte web UI (English, German, French, Spanish) with browser auto-detection, localStorage persistence, and account-level persistence for logged-in users.

**Architecture:** `i18next` + `react-i18next` + `i18next-browser-languagedetector`, initialized once before `<App>` renders. i18next's active language is the single source of truth; localStorage `lang` is the cross-session cache; a new nullable `users.language` column is the cross-device record. A small `setLanguage` helper centralizes "change locale + cache + (if authed) PATCH /me". Deck content is never translated.

**Tech Stack:** React 18, Vite, react-router, Tailwind, i18next/react-i18next, Express + Postgres server, Vitest.

**Spec:** `docs/superpowers/specs/2026-06-09-web-i18n-design.md`

- [ ] **Step 4: Implement `resolveLocale`**

```ts
export const SUPPORTED_LOCALES = ["en", "de", "fr", "es"] as const;
export type SupportedLocale = (typeof SUPPORTED_LOCALES)[number];
export const FALLBACK_LOCALE: SupportedLocale = "en";

export function resolveLocale(tag: string | null | undefined): SupportedLocale {
  if (!tag) return FALLBACK_LOCALE;
  const base = tag.toLowerCase().split("-")[0];
  return (SUPPORTED_LOCALES as readonly string[]).includes(base)
    ? (base as SupportedLocale)
    : FALLBACK_LOCALE;
}
```

- [ ] **Step 7: Implement `i18n/index.ts`**

```ts
import i18n from "i18next";
import { initReactI18next } from "react-i18next";
import LanguageDetector from "i18next-browser-languagedetector";
import { SUPPORTED_LOCALES, FALLBACK_LOCALE } from "./resolveLocale";
import en from "./locales/en.json";
import de from "./locales/de.json";
import fr from "./locales/fr.json";
import es from "./locales/es.json";

export { SUPPORTED_LOCALES } from "./resolveLocale";
export type { SupportedLocale } from "./resolveLocale";

i18n
  .use(LanguageDetector)
  .use(initReactI18next)
  .init({
    resources: {
      en: { translation: en },
      de: { translation: de },
      fr: { translation: fr },
      es: { translation: es },
    },
    fallbackLng: FALLBACK_LOCALE,
    supportedLngs: SUPPORTED_LOCALES as unknown as string[],
    load: "languageOnly", // de-AT -> de
    nonExplicitSupportedLngs: true,
    detection: {
      // localStorage cache wins; then browser; we persist to "lang".
      order: ["localStorage", "navigator"],
      lookupLocalStorage: "lang",
      caches: ["localStorage"],
    },
    interpolation: { escapeValue: false },
    returnNull: false,
  });

export default i18n;
```

- [ ] **Step 3: Implement `setLanguage`**

```ts
import i18n from "./index";
import { api } from "../api/client";
import { resolveLocale } from "./resolveLocale";

export async function setLanguage(
  lang: string,
  opts: { authed: boolean },
): Promise<void> {
  const loc = resolveLocale(lang);
  await i18n.changeLanguage(loc);
  try {
    localStorage.setItem("lang", loc);
  } catch {
    // ignore storage failures (private mode etc.)
  }
  if (opts.authed) {
    try {
      await api.auth.updateProfile(undefined, loc);
    } catch {
      // non-fatal: local choice still applied
    }
  }
}
```

```tsx
import { useTranslation } from "react-i18next";
import { useAuth } from "../auth/AuthContext";
import { setLanguage } from "../i18n/setLanguage";
import { SUPPORTED_LOCALES } from "../i18n";

export function LanguageSwitcher({ compact = false }: { compact?: boolean }) {
  const { t, i18n } = useTranslation();
  const { authed } = useAuth();
  const current = i18n.language;

  return (
    <select
      aria-label={t("language.label")}
      value={SUPPORTED_LOCALES.includes(current as never) ? current : "en"}
      onChange={(e) => setLanguage(e.target.value, { authed })}
      className={
        compact
          ? "rounded-md border border-white/15 bg-white/5 px-2 py-1 text-xs text-slate-200"
          : "rounded-lg border px-3 py-2 text-sm"
      }
    >
      {SUPPORTED_LOCALES.map((loc) => (
        <option key={loc} value={loc} className="text-black">
          {t(`language.${loc}`)}
        </option>
      ))}
    </select>
  );
}
```

## Notes for the implementer

- **Default test locale is `en`** — i18next initializes to `en` in jsdom (no localStorage, no navigator match), so existing tests that assert English text mostly keep working once literals map to identical `en` values. Where a test imports a page that now calls `useTranslation`, ensure `import "../i18n"` runs (it's imported transitively via components; if a test renders a component in isolation and sees raw keys, add `import "../../i18n"` to that test file).
- **Never** put deck/card content, emails, API keys, or plan codes through `t()`.
- Keep interpolation variable names identical across all four locale files.
- The `language.*` display names are deliberately each in their own language and are not "translated" per active locale.
